# 💻 Windows 12 Web Demo

Một dự án mã nguồn mở mô phỏng lại giao diện hệ điều hành **Windows 12** (Concept) chạy hoàn toàn trên nền tảng Web bằng HTML, CSS, JavaScript và được tối ưu hóa xử lý dữ liệu với **Remeda**.

👉 **[XEM DEMO TRỰC TIẾP TẠI ĐÂY](https://thvinhtangdvl-ship-it.github.io/windows-12-demo/)**

---

## ✨ Tính năng nổi bật

- 🖥️ **Giao diện Windows 12 Concept:** Thiết kế thanh Taskbar dạng Dock bo góc (Floating Taskbar), Menu Start tích hợp thanh tìm kiếm thông minh.
- 🪟 **Quản lý cửa sổ:** Hỗ trợ mở, đóng và tương tác với các ứng dụng (Settings, Browser, Notepad) mượt mà.
- ⚡ **Tối ưu bằng Remeda:** Sử dụng thư viện `remeda` để xử lý các tác vụ lọc ứng dụng, quản lý trạng thái (state) hệ thống một cách nhanh chóng, nhẹ nhàng và chuẩn TypeScript.
- 🎨 **Responsive Design:** Giao diện co giãn tốt trên nhiều kích thước màn hình máy tính khác nhau.

---

## 🛠️ Công nghệ sử dụng

Dự án được xây dựng dựa trên các công nghệ cốt lõi:

| Công nghệ / Thư viện | Vai trò |
| :--- | :--- |
| **HTML5 & CSS3** | Xây dựng khung sườn cấu trúc và làm đẹp giao diện (Blur effect, Glassmorphism). |
| **JavaScript (ES6+)** | Xử lý logic tương tác người dùng (Click, Ẩn/Hiện cửa sổ). |
| **Remeda** | Quản lý dữ liệu mảng, lọc các tiến trình (processes) đang chạy ngầm. |
| **GitHub Pages** | Lưu trữ và phát hành trang web demo miễn phí. |
